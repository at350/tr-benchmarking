# cases

Plain-text copies of the three appellate opinions the workflow demo is built on. Court
opinions are public records and not subject to copyright; the editorial synopsis and
headnotes that a commercial database adds to its printouts have been removed, so what
remains is the court's own text. The packets under `legal-workflow-data/` were built from
these opinions and hold their own extracted copies.

| File | Case | Statute of Frauds provision |
|---|---|---|
| `Westside_Wrecker_Service_v_Skafi_2011.txt` | Westside Wrecker Service, Inc. v. Skafi, 361 S.W.3d 153 (Tex. App. 2011) | one-year rule |
| `Anglemire_v_Policemens_Benevolent_Assn_of_Chicago_1939.txt` | Anglemire v. Policemen's Benevolent Ass'n of Chicago, 301 Ill. App. 277 (1939) | promises in consideration of marriage |
| `Demeritt_v_Bickford_1879.txt` | Demeritt v. Bickford, 58 N.H. 523 (1879) | suretyship |

To use another opinion, upload it as a PDF or text file on the `/legal-workflow` page; the
portal extracts the text and stores it under `legal-workflow-data/artifacts-v2/`.
